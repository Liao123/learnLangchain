# 第 17 课：记录多专员处理轨迹

## 这课学什么

把一次请求经过的总调度和专员处理过程，写入 JSON 文件。

## 解决什么问题

用户拿到错误答案时，只看最终答案不知道是“总调度选错专员”，还是“专员处理错了”。

## 什么场景会用

线上客服出现问题、评测有失败题、或新加一个专员后，要查看每一步实际怎么走。

## 你现在要做的

1. 在项目根目录运行：

   ```powershell
   py .\MultiAgentDemo\17_记录多专员处理轨迹\demo.py
   ```

2. 输入：

   ```text
   我想退钱
   ```

3. 打开本课的 `输出\trace.json`。

## 你会看到什么

```json
{
  "route": "refund",
  "trace": [
    {"node": "总调度", "decision": "选择 refund，进入 refund_agent"},
    {"node": "退款专员", "decision": "查询退款规则并生成答复"}
  ]
}
```

一句话：轨迹就是把 AI 的处理过程留下来。答案错了，先看它走到了哪个专员，再决定该改哪里。
