# 多 Agent 第 4 课：专员使用自己的提示词

## 这节课学什么

总调度选中专员后，对应专员再调用一次模型，用自己的规则和资料回答用户。

```text
用户问题
-> 总调度模型：返回 route="refund"
-> 退款专员模型：带着退款规则回答
-> 用户看到最终回答
```

## 解决什么问题

总调度只负责“交给谁”，不该同时掌握全部订单和退款规则。

订单专员只看订单资料；退款专员只看退款资料。这样职责更清楚，也减少无关资料混入回答。

## 运行前

需要设置 `DEEPSEEK_API_KEY`，并确保账户有可用余额。

## 运行

```powershell
py .\MultiAgentDemo\04_专员使用自己的提示词\demo.py
```

输入：

```text
我想退钱，什么时候到账？
```

观察：先打印“总调度 AI 选择：退款专员”，随后打印由退款专员模型生成的回答。

## 本课只记一句话

```text
多 Agent 不一定是多个不同模型；常见做法是同一个模型，用不同提示词、资料和工具扮演不同专员。
```
