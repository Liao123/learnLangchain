# 多 Agent 第 11 课：多专员并行汇总

## 这节课学什么

让订单专员和退款专员同时工作；等两人都完成后，父图再汇总。

## 解决什么问题

用户同时问订单状态和退款状态时，两次查询互不依赖。没必要先等订单专员结束，再启动退款专员。

```text
START
  -> Send(order_agent, {order_id: "A1001"})
  -> Send(refund_agent, {refund_id: "R2001"})
       两位专员并行
             ↓ 两人都完成
          summarize
             ↓
            END
```

## 运行

```powershell
py .\MultiAgentDemo\11_多专员并行汇总\demo.py
```

## 观察结果

两个专员都各等待 1 秒，但总耗时接近 1 秒：

```text
父图汇总：两位专员都已完成。
最终汇总：订单 A1001：配送中；退款单 R2001：处理中
总耗时约：1.0 秒
```

## 本课只记一句话

```text
Send 负责分出多个专员任务；add_edge(["A", "B"], "C") 负责等待 A、B 都完成后再汇总。
```
