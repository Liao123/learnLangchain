# 多 Agent 第 3 课：总调度多轮委派

## 这节课学什么

总调度不只分流一次。它可以先委派一个专员，等结果写回 state，再决定是否委派下一个专员。

## 解决什么问题

退款前往往要先确认订单状态。退款专员不能凭空办理，而要先拿到订单专员的查询结果。

```text
用户：我想退订单 A1001
  ↓
总调度：先查订单状态
  ↓
订单专员：写入 order_status = "已签收"
  ↓
总调度：再办理退款
  ↓
退款专员：写入 refund_result
  ↓
总调度：结果齐全，结束
```

## 运行

```powershell
py .\MultiAgentDemo\03_总调度多轮委派\demo.py
```

## 观察结果

```text
总调度：先委派订单专员，确认订单是否可以退款。
订单专员：查到订单 A1001 状态是“已签收”。
总调度：订单状态已确认，再委派退款专员。
退款专员：确认订单状态是“已签收”，提交退款申请。
总调度：所需结果已齐，结束流程。
```

## 本课只记一句话

```text
专员完成后回到总调度；总调度根据 state 里已有的结果，决定下一位专员或结束。
```
