# 多 Agent 第 1 课：多专员分流工作流

## 这节课学什么

用一个总调度节点，把用户问题交给不同的专员子图。

## 解决什么问题

订单问题和退款问题的资料、规则、工具不同。不能每次都让一个节点处理所有问题。

```text
用户问题
   ↓
总调度 router
 ├─ 订单问题 -> 订单专员子图
 └─ 退款问题 -> 退款专员子图
   ↓
返回对应专员的回答
```

## 运行

```powershell
py .\MultiAgentDemo\01_多专员分流工作流\demo.py
```

## 观察结果

```text
总调度：交给订单专员。
订单专员子图：回答订单问题。
最终回答：订单 A1001 正在配送中，预计今天送达。

总调度：交给退款专员。
退款专员子图：回答退款问题。
最终回答：退款申请提交后，通常会在 1 到 3 个工作日原路退回。
```

## 注意

本课的总调度暂时用 `if "退款" in question` 模拟分流，目的是先看清多专员图的结构。它还不是让 AI 自己理解问题；下一步才会把总调度替换成模型节点。

## 本课只记一句话

```text
多专员工作流的关键不是“所有专员都回答”，而是总调度把每次问题交给最合适的一个专员。
```
