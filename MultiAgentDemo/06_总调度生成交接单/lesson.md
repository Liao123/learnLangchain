# 多 Agent 第 6 课：总调度生成交接单

## 这节课学什么

总调度除了选择下一个专员，还把单号、任务等必要信息写成 `handoff`，交给下一位专员。

## 解决什么问题

如果总调度已经从“订单 A1001 到哪里了”识别出订单号，就不必让订单专员再从原句里提取一次。

```text
用户：订单 A1001 到哪里了？
  ↓
总调度交接单：
{route: "order", record_id: "A1001", task: "查询配送进度"}
  ↓
订单专员只读取 record_id="A1001" 并查询订单
```

## 运行前

需要设置 `DEEPSEEK_API_KEY`，并确保账户有可用余额。

## 运行

```powershell
py .\MultiAgentDemo\06_总调度生成交接单\demo.py
```

输入：

```text
订单 A1001 到哪里了？
```

观察类似输出：

```text
总调度交接单：{'route': 'order', 'record_id': 'A1001', 'task': '查询配送进度'}
最终回答：订单专员：订单 A1001 配送中，预计今天送达。
```

## 本课只记一句话

```text
handoff 是总调度交给下一个专员的结构化工作单，只放下一步真正需要的数据。
```
