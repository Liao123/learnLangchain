# 多 Agent 第 15 课：评测总调度路由

## 这节课学什么

用一组固定问题，真实调用模型，检查总调度是否选择了人工预期的 route。

## 解决什么问题

修改总调度提示词、模型或路由规则后，不能只随便问一句“看起来能跑”就算完成。

需要同一组测试问题反复运行，对比成功率是否下降。

```text
测试问题 + 人工预期 route
  -> 调用总调度模型
  -> 读取实际 route
  -> 逐条比较
  -> 统计成功率
```

## 运行前

需要设置 `DEEPSEEK_API_KEY`，并确保账户有可用余额。

## 运行

```powershell
py .\MultiAgentDemo\15_评测总调度路由\demo.py
```

## 观察结果

```text
第 1 条：通过
  问题：订单 A1001 到哪里了？
  期望 route：order
  实际 route：order

总结果：4/4，成功率 100%
```

实际模型可能并非每次都是 100%。遇到失败时，先看哪一条问题被错误分流，再决定调整提示词、增加示例，还是新增专员路线。

## 本课只记一句话

```text
评测不是只看程序有没有报错，而是用固定问题验证模型行为是否仍符合业务预期。
```
