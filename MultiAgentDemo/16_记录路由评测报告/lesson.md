# 第 16 课：记录路由评测报告

## 这课学什么

把每次总调度的评测结果写进一个 JSON 文件，并单独列出失败题。

## 解决什么问题

只看到“成功率 75%”时，不知道是哪道题选错了，也不知道下次改完有没有进步。

## 什么场景会用

你改了总调度的提示词、换了模型，或增加了新业务路线后，都重新跑同一批题，比较报告。

## 你现在要做的

1. 在项目根目录运行：

   ```powershell
   py .\MultiAgentDemo\16_记录路由评测报告\demo.py
   ```

2. 终端会逐题显示“通过”或“失败”。

3. 打开本课的 `输出\route_evaluation_report.json`，看完整结果。

## 你要观察的内容

某题失败时，报告会像这样：

```json
{
  "question": "我不想要了，钱什么时候退回来？",
  "expected_route": "refund",
  "actual_route": "order",
  "passed": false,
  "case_type": "退款意图"
}
```

这说明：不是“模型表现不好”这么笼统，而是“退款意图这类题被误分到订单”。接下来才有依据去改总调度提示词或补测试题。

一句话：评测不是只算分，而是留下每一道错题，告诉你下一步该改哪里。
