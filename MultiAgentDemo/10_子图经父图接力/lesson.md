# 多 Agent 第 10 课：子图经父图接力

## 这节课学什么

多个专员子图不直接互相跳转，而是都交回父图总调度，由父图决定下一位专员。

## 解决什么问题

退款专员需要订单状态，但订单专员不应该直接决定“接下来是否退款”。这属于总调度的职责。

```text
父图 supervisor
  -> 订单子图 order_team
  -> Command.PARENT 回父图 supervisor
  -> 退款子图 refund_team
  -> Command.PARENT 回父图 final_reply
  -> END
```

## 运行

```powershell
py .\MultiAgentDemo\10_子图经父图接力\demo.py
```

## 观察结果

```text
父图总调度：先进入订单子图。
订单子图：查到订单 A1001 已签收。
父图总调度：订单状态已返回，现在进入退款子图。
退款子图：确认订单状态是“已签收”，提交退款。
父图：收到退款子图结果，统一生成最终回复。
```

## 本课只记一句话

```text
专员子图负责完成自己的工作；父图总调度负责决定下一位专员，避免专员之间互相硬编码跳转。
```
