# 多 Agent 第 5 课：专员只拥有自己的工具

## 这节课学什么

给不同专员绑定不同工具，形成明确的权限边界。

```text
订单专员 -> 只有 get_order_status
退款专员 -> 只有 get_refund_status
```

## 解决什么问题

不能因为系统里存在退款工具，就让订单专员也能调用它。

生产系统会按专员职责、用户身份和业务风险限制工具。模型负责提出工具请求，Python 只执行当前专员白名单里的工具。

## 运行前

需要设置 `DEEPSEEK_API_KEY`，并确保账户有可用余额。

## 运行

```powershell
py .\MultiAgentDemo\05_专员只拥有自己的工具\demo.py
```

输入：

```text
订单 A1001 到哪里了？
```

观察类似过程：

```text
总调度：交给订单专员。
专员调用工具：get_order_status，参数：{'order_id': 'A1001'}
最终回答：订单专员：订单 A1001 正在配送中，预计今天送达。
```

也可以输入：

```text
退款单 R2001 什么时候到账？
```

## 本课只记一句话

```text
多 Agent 的权限边界不是只写在提示词里，而是每个专员实际只绑定自己的工具列表。
```
