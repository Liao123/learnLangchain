# 多 Agent 第 14 课：操作人权限校验

## 这节课学什么

退款专员从 `config` 读取当前操作人身份和角色，再决定是否允许执行退款。

## 解决什么问题

“退款专员拥有退款能力”不等于“任意客服都能让它退款”。

```text
专员工具白名单：退款专员具备退款能力。
操作人权限校验：当前这位操作人是否有权使用这项能力。
```

## 运行

```powershell
py .\MultiAgentDemo\14_操作人权限校验\demo.py
```

## 观察结果

```text
退款子图：当前操作人是 小李，角色是 customer_service。
客服回复：小李 没有退款审批权限，退款没有提交。

退款子图：当前操作人是 小周，角色是 refund_approver。
客服回复：小周 已批准订单 A1001 的 28.0 元退款。
```

## 本课只记一句话

```text
模型和用户输入不能决定权限；权限应来自服务端可信的运行 config，并在执行工具前由 Python 校验。
```
