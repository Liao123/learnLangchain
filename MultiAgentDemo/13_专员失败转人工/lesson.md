# 多 Agent 第 13 课：专员失败转人工

## 这节课学什么

专员调用业务系统失败时，捕获已知错误，写入失败原因，并交回父图转人工客服。

## 解决什么问题

订单系统、支付系统、模型接口都可能暂时失败。不能把 Python traceback 直接展示给用户，也不能让模型猜一个业务结果。

```text
订单子图查订单
  ├─ 成功 -> 回父图 final_reply
  └─ ConnectionError -> 回父图 human_service
```

## 运行

```powershell
py .\MultiAgentDemo\13_专员失败转人工\demo.py
```

## 观察结果

```text
订单子图：查到订单 A1001 状态是“配送中”。
正常订单：订单 A1001 当前配送中。

订单子图：查订单失败，交回父图转人工客服。
失败订单：订单 A5000 暂时无法查询，已转人工客服处理。
```

## 本课只记一句话

```text
业务系统失败不是让整个多 Agent 程序崩掉的理由；专员应把已知失败交回父图，父图选择人工或其他降级路线。
```
