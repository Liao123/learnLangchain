# 第 55 课：订单查询工具

## 这节只记一句

工具就是一个“给它输入，拿回结果”的 Python 函数。

```text
订单号 A1001
-> 查询订单工具
-> 返回订单状态
-> 程序告诉用户结果
```

## 直接做

### 1. 运行

```powershell
py .\WorkflowDemo\01_订单查询工具\demo.py
```

### 2. 看结果

终端会显示：

```text
用户订单号：A1001
工具返回：{'found': True, '商品': '冰拿铁', '状态': '制作中', ...}
给用户：您的冰拿铁正在制作中，取餐号是 18。
```

### 3. 自己试一次失败情况

把 `demo.py` 里的：

```python
user_order_id = "A1001"
```

改成：

```python
user_order_id = "B9999"
```

再运行，会看到“没有找到这个订单”。

这就是 workflow 的第一步：**程序提前写好规则，决定调用哪个工具。**
