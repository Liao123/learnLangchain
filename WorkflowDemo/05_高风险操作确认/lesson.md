# 第 59 课：取消订单前必须确认

## 这节只记一句

AI 可以提出操作，但取消订单这种会改变数据的操作，必须等用户确认后才能执行。

```text
用户：取消 A1002
-> AI 提取订单号
-> 程序显示“准备取消”
-> 用户输入 确认
-> 程序才真的取消
```

## 直接做

### 1. 设置 Key 后运行

```powershell
$env:DEEPSEEK_API_KEY="你的Key"
py .\WorkflowDemo\05_高风险操作确认\demo.py
```

### 2. 终端问你是否确认时

输入：

```text
确认
```

会看到：

```text
给用户：美式咖啡订单已取消。
```

输入其他文字，订单不会取消。

这不是普通按钮确认，而是 AI workflow 的规则：**模型不能自己执行高风险操作。**
