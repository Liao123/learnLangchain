# 第 57 课：AI 提取参数，业务流程做决定

## 这节只记一句

AI 可以从用户的话里提取订单号，但“能不能取消”必须由程序的业务规则决定。

```text
用户：帮我取消订单 A1001
-> AI 提取：A1001
-> 程序查订单：制作中
-> 程序规则：制作中不能取消
-> 返回结果
```

## 直接做

### 1. 先设置 DeepSeek Key

```powershell
$env:DEEPSEEK_API_KEY="你的Key"
```

### 2. 运行

```powershell
py .\WorkflowDemo\03_AI提取参数与业务校验\demo.py
```

### 3. 看关键输出

```text
AI 提取的订单号：A1001
订单当前状态：制作中
给用户：订单已经开始制作，暂时不能取消。
```

### 4. 改一个问题再运行

把：

```python
question = "帮我取消订单 A1001"
```

改成：

```python
question = "请帮我取消 A1002"
```

`A1002` 是“待制作”，程序会真的把它改成“已取消”。
