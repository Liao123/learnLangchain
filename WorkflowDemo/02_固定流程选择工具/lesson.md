# 第 56 课：固定流程选择工具

## 这节只记一句

workflow 就是程序提前写好规则，决定调用哪个工具。

```text
用户要查营业时间
-> 程序判断：调用营业时间工具
-> 工具返回周末时间
-> 程序显示结果
```

## 直接做

### 1. 运行

```powershell
py .\WorkflowDemo\02_固定流程选择工具\demo.py
```

### 2. 看结果

终端会显示：

```text
用户要做：查营业时间
程序调用：查询营业时间工具
给用户：周末营业时间是 09:00 至 21:00。
```

### 3. 自己改一个值再运行

把：

```python
user_action = "查营业时间"
```

改成：

```python
user_action = "查订单"
```

程序会改为调用订单查询工具。
