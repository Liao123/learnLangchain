# 模块 18：缓存容量限制

## 这节课在学什么？

缓存不能无限增加，否则内存会越来越大。这一课让缓存最多只保留 2 条，并删除最久没有被使用的那一条。

一句话逻辑：

```text
缓存超过最大数量
-> 删除最久未使用的数据
-> 留下最近还在使用的数据
```

这种规则叫 LRU：Least Recently Used，意思是“最久未使用”。

## 程序运行时发生了什么？

```text
最大容量：2

加入 q1、q2
-> 顺序：[q1, q2]

再次使用 q1
-> q1 变成最近使用
-> 顺序：[q2, q1]

加入 q3
-> 临时顺序：[q2, q1, q3]
-> 超过 2 条
-> 删除最久未使用的 q2
-> 最终顺序：[q1, q3]
```

## 这节要记住

- `OrderedDict` 是 Python 自带的“有顺序字典”。
- `move_to_end(key)` 把刚刚使用的 key 移到最后，表示它最新。
- `popitem(last=False)` 删除最前面的 key，也就是最久未使用的那一条。
- 容量限制解决“缓存太多”；TTL 解决“缓存太旧”；知识库版本解决“资料更新”。
