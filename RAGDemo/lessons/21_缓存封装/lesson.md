# 模块 21：缓存封装

## 这节课在学什么？

第 43 到 48 课分别写过缓存命中、版本、TTL、容量、权限。现在把这些重复规则收进一个 `RetrievalCache` 对象里。

一句话逻辑：

```text
以前：demo 自己写字典、key、TTL、删除逻辑
现在：demo 只调用 cache.set() 和 cache.get()
```

## 这节要记住

- `cache.make_key(...)`：生成包含权限、版本、问题的 key。
- `cache.set(...)`：保存检索结果，必要时删除最久未使用的缓存。
- `cache.get(...)`：有缓存且没过期就返回 result；没有或过期就返回 `None`。
- 封装不是增加功能，而是把已经学过、会重复出现的代码放到一个地方维护。

## 程序运行时发生了什么？

```text
创建缓存：最多 2 条，TTL 300 秒
-> 存“周末营业”
-> 存“会员积分”
-> 读取“周末营业”：命中，变成最近使用
-> 存“退款规则”：超过 2 条，删除“会员积分”
-> 到第 1400 秒再读取“周末营业”：年龄 400 秒，超过 TTL，返回 None
```
