# 模块 20：缓存安全

## 这节课在学什么？

同一个问题，不同用户的权限可能不同，所以不能只用“问题文字”当缓存 key。

一句话逻辑：

```text
缓存 key = 用户权限 + 知识库版本 + 问题
-> 不同权限得到不同 key
-> 不会拿到别人的缓存资料
```

## 它解决什么问题？

金卡会员问：`我有什么会员优惠？`，缓存里可能有“现制饮品九折优惠”。

如果普通会员问同样的问题，而缓存 key 只有：

```python
"我有什么会员优惠？"
```

普通会员可能错误读到金卡优惠，这是权限泄露。

正确做法是：

```python
"gold:v1:我有什么会员优惠？"
"normal:v1:我有什么会员优惠？"
```

它们是两个不同缓存 key。

## 程序运行时发生了什么？

```text
金卡会员提问
-> key：gold:v1:我有什么会员优惠？
-> 保存金卡资料

普通会员问同一个问题
-> key：normal:v1:我有什么会员优惠？
-> 和 gold key 不同
-> 不命中金卡缓存
-> 应按普通会员权限重新检索
```

## 这节要记住

- 缓存命中很快，但命中错数据比不缓存更危险。
- 权限、租户、用户角色、知识库版本、问题，都可能是缓存 key 的一部分。
- 本课用 `gold`、`normal` 模拟会员身份；真实系统通常用用户 ID、租户 ID 或权限版本。
