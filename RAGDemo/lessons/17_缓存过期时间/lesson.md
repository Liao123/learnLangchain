# 模块 17：缓存过期时间

## 这节课在学什么？

第 44 课用知识库版本避免旧资料命中缓存。这一课再加一个规则：即使资料版本没变，缓存保存太久也不能一直使用。

一句话逻辑：

```text
缓存年龄 = 当前时间 - 保存时间
-> 年龄没有超过 TTL：缓存有效
-> 年龄超过 TTL：缓存过期，重新检索
```

`TTL` 是 Time To Live，意思是“缓存允许活多久”。

## 程序运行时发生了什么？

本课用模拟时间，不需要真的等 5 分钟。

```text
缓存保存时间：1000 秒
TTL：300 秒

当前时间 1100 秒
-> 缓存年龄 = 1100 - 1000 = 100 秒
-> 100 <= 300
-> 缓存有效

当前时间 1400 秒
-> 缓存年龄 = 1400 - 1000 = 400 秒
-> 400 > 300
-> 缓存过期
```

## 这节要记住

- 缓存条目除了 `result`，还要保存 `saved_at`（保存时刻）。
- `CACHE_TTL_SECONDS = 300` 表示最多使用 300 秒，也就是 5 分钟。
- 版本变化解决“资料更新”；TTL 解决“时间太久”。两者可以一起使用。
- 真实程序通常用 `time.time()` 得到当前秒数；本课用固定数字，方便你看清计算。
