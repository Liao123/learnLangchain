# app 怎么看

打开 `app`，先看中文文件夹名，不用先看里面的代码：

```text
聊天问答/      平时和知识库聊天
知识库构建/    改资料后，重新生成索引
质量检查/      重建后，检查资料有没有找错
检索核心/      上面程序会用到的内部代码，暂时不用看
功能演示/      以前课程的单项复习，想复习再看
```

你现在只会直接运行这 3 个文件：

```powershell
# 平时问答
py .\RAGDemo\app\聊天问答\rag_cli.py

# 修改真实知识库资料后
py .\RAGDemo\app\知识库构建\build_parent_child_index.py

# 重建后检查
py .\RAGDemo\app\质量检查\evaluate_retrieval.py
```

其他 Python 文件都是上面三个程序自动调用的，当前不用打开。
