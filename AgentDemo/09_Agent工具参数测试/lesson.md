# 第 68 课：Agent 工具参数测试

这节课学什么：测试 Agent 不但选对工具，也把用户提供的参数提取正确。

本课解决什么问题：`get_order_status` 选对了，但把 `A1001` 写成 `A1002`，结果仍然是错的。

场景：上线前检查订单号、会员 ID 是否会被正确放入工具参数。

## 直接运行

1. 在 PowerShell 设置好 `DEEPSEEK_API_KEY`。
2. 运行：

```powershell
py .\AgentDemo\09_Agent工具参数测试\demo.py
```

3. 看每题的“实际参数”。默认预期是 `3 / 3` 通过。

## 本课只记一句话

工具测试要同时比较：

```text
工具名是否正确 + 参数字典是否正确
```
