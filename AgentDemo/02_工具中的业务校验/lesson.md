# 第 61 课：工具中的业务校验

这节课学什么：AI 可以选择调用“取消订单”工具；但订单到底能不能取消，由工具里的 Python 规则决定。

本课解决什么问题：不能只靠提示词限制 AI。即使 AI 错误地请求取消，代码也必须挡住不允许的操作。

场景：客服 Agent 帮用户取消订单，但订单已经制作中。

## 直接运行

1. 在 PowerShell 设置好 `DEEPSEEK_API_KEY`。
2. 运行：

```powershell
py .\AgentDemo\02_工具中的业务校验\demo.py
```

3. 看输出：Agent 可以请求取消；但工具返回“订单已制作中，不能取消”。

## 本课只看这里

```python
if order["状态"] != "待制作":
    return "取消失败：订单已制作中，不能取消。"
```

这一段是最终业务规则。模型的请求不能越过它。
