# 第 63 课：Agent 执行轨迹

这节课学什么：把 Agent 每一轮做的事记录下来，最后打印成 JSON。

本课解决什么问题：Agent 没回答、选错工具或调用很多轮时，不能只看最终答案，要能看到中间过程。

场景：线上客服回答错误后，开发者需要知道它查了什么、工具实际返回了什么。

## 直接运行

1. 在 PowerShell 设置好 `DEEPSEEK_API_KEY`。
2. 运行：

```powershell
py .\AgentDemo\04_Agent执行轨迹\demo.py
```

3. 看最后的“本次执行轨迹”。默认题目预计会有：

```text
第 1 轮：请求 get_order_status
第 1 轮：工具返回“制作中”
第 2 轮：最终答复
```

## 只记一句话

`trace` 不是给 AI 看的资料，而是给开发者排查问题的运行记录。
