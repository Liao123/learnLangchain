# 第 67 课：Agent 工具选择测试

这节课学什么：用固定题目自动检查 Agent 会不会选对工具。

本课解决什么问题：修改提示词、添加工具或更换模型后，Agent 可能把“查积分”错选成“查订单”。人靠手工一题题试，很容易漏掉。

场景：上线前跑 3 道固定题，检查订单、积分、营业时间分别对应正确的工具。

## 直接运行

1. 在 PowerShell 设置好 `DEEPSEEK_API_KEY`。
2. 运行：

```powershell
py .\AgentDemo\08_Agent工具选择测试\demo.py
```

3. 看最后一行：默认预期是 `3 / 3` 通过。

## 本课只记一句话

这次不执行工具，只测 Agent 的第一步选择：

```text
用户问题 -> AI 请求的工具名 -> 和预期工具名比较
```
