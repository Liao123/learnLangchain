# Agent Harness 第 2 课：批量回归评测

## 这课学什么

让 Harness 依次运行一组固定任务，得到总分和每道题的完整记录。

## 解决什么问题

只测一题，无法知道 Agent 整体是否变好。更危险的是：你修好退款题，却把订单题改坏了。

## 什么场景会用

你改了提示词、模型、工具或 LangGraph 流程后，重新运行同一组任务。

## 你现在要做的

1. 在项目根目录运行：

   ```powershell
   py .\AgentHarnessDemo\02_批量回归评测\demo.py
   ```

2. 终端会显示四道题分别通过还是失败。

3. 打开本课的 `输出\batch_report.json`。

## 你要看什么

```json
{
  "summary": {
    "total_count": 4,
    "passed_count": 4,
    "success_rate": 1.0
  }
}
```

重点不是这一次是否 100%，而是以后每次修改后都跑同一组题。

如果原来是 `4/4`，改完变成 `3/4`，这次改动就是回归：新代码让旧能力退步了。

一句话：回归评测就是用固定题集守住已经正常的能力。
