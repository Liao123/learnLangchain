# Agent Harness 第 15 课：并行批量评测

## 这课学什么

同时运行多道模型评测题，但限制同一时刻最多两次 API 请求。

## 解决什么问题

串行跑 100 道题，要等待 100 次模型回复。并行可以缩短总时间，但一次发太多请求又可能触发限流。

## 你现在要做的

在项目根目录运行：

```powershell
py .\AgentHarnessDemo\15_并行批量评测\demo.py
```

打开 `输出\parallel_evaluation_report.json`。

## 你要先这样理解

```text
第 1、2 题同时请求模型
第 1 题完成后，第 3 题开始
第 2 题完成后，第 4 题开始
全部完成后，生成报告
```

`MAX_CONCURRENT_REQUESTS = 2` 就是“同时最多两题”。

## 新语法先记住作用

`async def`：声明一个可以等待网络请求的函数。

`await`：等待这道题的网络回复时，让 Python 有机会处理其他题。

`asyncio.gather(...)`：一起启动一组题，并等全部结束。

一句话：并行评测不是让模型更聪明，而是让大量独立测试题更快跑完，同时控制接口压力。
