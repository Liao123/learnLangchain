# Agent Harness 第 7 课：模型评审开放答案

## 这课学什么

当回答不是固定选项时，用第二个模型按人工评分标准评审回答。

## 解决什么问题

下面两句话表达的意思相同，但字符串不相等：

```text
通常会在 1 到 3 个工作日原路退回。
退款会退回原支付方式，到账时间是 1-3 个工作日。
```

所以不能再用 `actual == expected` 判断回答对不对。

## 你现在要做的

在项目根目录运行：

```powershell
py .\AgentHarnessDemo\07_模型评审开放答案\demo.py
```

它会调用两次模型：退款 Agent 回答一次，评审模型判分一次。

打开 `输出\judge_record.json`，看：

```json
{
  "agent_answer": "...",
  "evaluation": {
    "passed": true,
    "reason": "...",
    "missing_points": []
  }
}
```

## 你要记住

评分标准 `rubric` 是人写的，不能让被测 Agent 自己决定标准。

评审模型也会出错，所以后面还要专门测试它的判分是否可靠；它不能单独决定退款、风控等高风险操作。

一句话：开放式回答没有唯一标准文本时，用独立模型按明确标准判分。
