# Agent Harness 第 16 课：失败请求重试

## 这课学什么

模型请求遇到临时连接错误时，有限次数重试，并记录每次尝试。

## 解决什么问题

一次网络抖动不代表 Agent 答错了。如果直接计为失败，会把服务故障误判成模型能力问题。

## 你现在要做的

在项目根目录运行：

```powershell
py .\AgentHarnessDemo\16_失败请求重试\demo.py
```

本课不调用 DeepSeek。为了稳定演示，它固定模拟：前两次连接失败，第三次成功。

你会看到：

```text
第 1 次：connection_error
第 2 次：connection_error
第 3 次：success
```

打开 `输出\retry_report.json`，看完整尝试记录。

## 你要记住

这里只捕获并重试 `ConnectionError`。

参数不合法、权限不足、用户未确认退款等错误，不应靠重试解决。

生产环境通常还会在两次重试之间等待一小段时间，避免反复冲击故障服务。

一句话：重试是给临时服务故障的，不是给业务错误找借口的。
