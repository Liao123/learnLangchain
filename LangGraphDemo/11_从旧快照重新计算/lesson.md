# LangGraph 第 11 课：从旧快照重新计算

## 这节课学什么

从某个历史快照修改数据，再只运行它后面的节点。

## 解决什么问题

订单已经算出 `2 × 12.5 = 25`，后来发现数量应该是 3。

不能只手动把最终总价改成 37.5；应该回到“计算总价之前”，修改数量，再让程序重新计算。

## 运行

```powershell
py .\LangGraphDemo\11_从旧快照重新计算\demo.py
```

## 观察结果

```text
原来的结果：订单 A1001：总价 25.0 元。
从旧快照改数量后重新计算：订单 A1001：总价 37.5 元。
```

## 这课的流程

```text
旧输入：quantity=2, unit_price=12.5
-> 旧结果：total=25.0

取“计算前”的旧快照
-> 把 quantity 改成 3
-> 从这个旧位置继续运行
-> 新结果：total=37.5
```

## 本课只记一句话

```text
旧快照不是只能看，也可以作为重新运行的起点。
```
