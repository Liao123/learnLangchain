# LangGraph 第 16 课：把子图当作节点

## 这节课学什么

把一张已经 `compile()` 的小图，作为主图的一个节点使用。

## 解决什么问题

主订单流程只需要知道：支付完成后才能创建订单。

它不需要把“检查余额、扣款”两步全写在主图里；这两步可以放进支付子图。

```text
主图：prepare_order -> payment 子图 -> finish_order

payment 子图内部：
check_balance -> deduct_balance
```

## 运行

```powershell
py .\LangGraphDemo\16_把子图当作节点\demo.py
```

## 观察结果

```text
主图：准备创建订单。
支付子图：检查余额。
支付子图：扣除余额。
主图：支付完成，创建订单。

最终回答：订单 A1001 创建成功，余额剩余 72.0 元。
```

## 本课只记一句话

```text
子图对主图来说是一个节点；对子图自己来说，内部仍然可以有多个节点和边。
```
