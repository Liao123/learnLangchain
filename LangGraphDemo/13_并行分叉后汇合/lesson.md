# LangGraph 第 13 课：并行分叉后汇合

## 这节课学什么

让两个互不依赖的节点同时运行；两个都完成后，再运行下一个节点。

## 解决什么问题

地址检查和库存检查互不依赖。如果一个完成后才开始另一个，会浪费时间。

```text
START
 ├─ check_address（约 1 秒）
 └─ check_stock（约 1 秒）
       两个都完成后
             ↓
       create_result
```

## 运行

```powershell
py .\LangGraphDemo\13_并行分叉后汇合\demo.py
```

## 观察结果

两个检查各等待 1 秒，但总耗时接近 1 秒，说明它们是同时进行的。

```text
最终结果：订单 A1001 可以继续处理：['已校验地址', '已检查库存']
总耗时约：1.0 秒
```

## 本课只记一句话

```text
add_edge(["节点A", "节点B"], "节点C") 的意思是：等 A 和 B 都完成，再执行 C。
```
